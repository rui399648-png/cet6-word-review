# 六级单词复习

把 Excel 生词本变成闪卡。双击一个 HTML 文件即可离线复习，无需安装应用或注册账号。

## 开始使用

1. 在本仓库点击 **Code → Download ZIP**，下载并解压。
2. 用 Edge 或 Chrome 打开 `六级单词复习.html`。
3. 点击“打开生词本”，选择自己的 `.xlsx` 文件。也可以先试用 [示例词书](examples/示例词书.xlsx)。
4. 选择范围，点击卡片翻面，再根据记忆情况选择“认识”“模糊”或“不认识”。

## 功能

- 多本词书分别管理，可按来源和掌握程度筛选。
- 支持五轮打卡，也能识别表格中其他数量的轮次。
- “认识”完成下一轮打卡；“模糊”留到队列末尾重练；“不认识”清空该词打卡并重练。
- 自动保存复习进度和未完成队列，下次继续上次尚未评分的词。
- 可回看上一张，支持空格翻面、数字键 `1 / 2 / 3` 评分。
- 英文朗读与自动朗读开关。朗读能力取决于浏览器及已安装的英文语音。
- 导出带打卡结果的 Excel，保留第一张工作表的原始字段和辅助列。
- 删除词书前确认，一并清理该词书的程序缓存、进度和续学断点，保留原 Excel 文件。

## Excel 格式

程序读取 **第一张工作表**，**第一行必须为表头**。

| 序号 | 单词 | 词性 | 中文释义 | 来源部分 | 第1轮 | 第2轮 | 第3轮 | 第4轮 | 第5轮 | 掌握程度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | reinforce | v. | 加强；强化 | 阅读 | □ | □ | □ | □ | □ | 陌生 |
| 2 | inevitable | adj. | 不可避免的 | 阅读 | □ | □ | □ | □ | □ | 陌生 |

必需列为“单词”和“中文释义”（也可使用“意思”）。其余列可选；需要打卡时请保留“第1轮”“第2轮”等列。轮次表头可以附带日期或换行。`□` 表示未打卡，`☑` 表示已打卡。

同一词书中的单词应保持唯一；程序按单词文字保存打卡状态。派生词、搭配可以写在中文释义中，原文词形和页码可作为额外列保留。

## 数据保存与备份

词书和复习进度保存在当前浏览器的 `localStorage` 中，程序没有服务器上传功能。更换浏览器、清理浏览器数据或使用隐私模式可能导致进度无法保留。使用本地文件时，移动 HTML 文件也可能改变浏览器采用的存储范围。

建议定期点击“导出打卡表格”备份。导出文件保留打卡状态，不包含未完成队列或原工作簿的排版、图片、其他工作表。存储失败时页面会给出提示。

## 开发

环境：Node.js 22 或更新版本、Python 3.10 或更新版本。使用成品 HTML 时不需要这些工具。

```bash
python -m pip install -r requirements-dev.txt
npm test
python build.py
```

如果 Python 命令是 `python3`，构建时使用 `python3 build.py`；测试会在非 Windows 系统上默认使用 `python3`。也可通过 `PYTHON` 环境变量指定解释器。

不需要安装 npm 依赖。Node 测试器内置于 Node.js，Excel 读写库已打包在 `vendor/`。

| 文件 | 用途 |
| --- | --- |
| `六级单词复习.html` | 可直接使用的离线应用 |
| `src/logic.js` | 词表解析、评分、队列与导出数据 |
| `src/storage.js` | 浏览器存储 |
| `src/ui.js` | 页面交互和复习流程 |
| `src/index.template.html`、`src/styles.css` | 页面结构和样式 |
| `build.py` | 将源码和依赖拼装为单个 HTML |
| `tests/` | 核心逻辑、存储、操作流程与 Excel 往返测试 |
| `examples/` | 通用示例词书 |

测试中的词表为合成数据，示例词书为独立编写的通用样本，不包含个人词书或试卷照片。
